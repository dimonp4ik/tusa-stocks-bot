# Учёт выхода по стопу б/у

Проверка 16 ноября 2026 воспроизвела ошибку для LONG и SHORT: после TP1 модель видела открытие следующей свечи за стопом б/у, но записывала цену входа и положительные +0,025R. Теперь известный гэп учитывается по открытию этой следующей свечи. Открытие свечи, предшествующее публикации/активации стопа, для такой подстановки не используется.

Тестовый пример: вход LONG 100, исходный стоп 99, TP1 100,5, модельная фиксация 5%. Следующая после активации свеча открывается на 99,4. Модельный результат составляет `0,05 × 0,5 + 0,95 × (99,4 − 100) = −0,545R`. Пример зеркально проверен для SHORT. Это оценка сигнала по публичной свече; собственные биржевые исполнения клиента подтверждаются отдельно и могут отличаться от открытия свечи.

Статус `BREAKEVEN` сохраняется как причина выхода по стопу, поставленному на уровень входа. Его название не определяет знак прибыли. Уведомление различает обычный выход и гэп, показывает расчётную цену/R и отсылает к отдельному уведомлению исполнения на счёте.

Цвета последних исходов, недельный винрейт, разбивка по инструментам и тренду теперь используют сохранённый R: отрицательный выход после TP1 — убыток, положительный выход по времени — прибыль, точный ноль — нейтральный исход. Последние исходы упорядочиваются по закрытию, а не по открытию позиции. В недельной разбивке `W/L` означает прибыльные/убыточные исходы; число `SL` отдельно сохраняет значение события исходного стопа.

Старые закрытые строки автоматически не переписываются: для их исправления нужны отдельные проверенные ценовые пути. Изменение не доказывает прибыльность стратегии или +30% ежемесячно. Новые варианты дальнего тейка и трейлинга остаются исследовательскими.
