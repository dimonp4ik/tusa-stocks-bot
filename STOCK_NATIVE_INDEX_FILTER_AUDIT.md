# Фильтр движения индекса: проверка 16 ноября 2026

Статус: исследование, без изменения торговых правил. Ни один из восьми вариантов не подтвердил +30% во всех полных месяцах; у каждого выросла модельная просадка хотя бы в одном полном месяце. Данных для включения в LIVE недостаточно.

Скрипт `stock_native_residual_close_nov16_audit.py` использует родные 15m котировки 44 инструментов и родные QQQ/SPY X-Perp. Сначала точно воспроизводятся 900 сделок предыдущего причинного расчёта, включая инструмент, направление, время входа/выхода и R. Сравнение повторно проводит весь портфельный допуск для 11 946 исходных кандидатов, а не просто удаляет проигравшие сделки из готового списка.

Бета оценивается по 96 предыдущим однобарным доходностям с минимумом 72 наблюдения, без участия сигнального бара. Остаточное движение — двухбарное движение инструмента за вычетом индексной компоненты; его шкала также использует только прошлые значения. Сравниваются четыре правила для каждого индекса:

- остаточное движение против направления входа не меньше 0,2%;
- то же плюс модуль остаточного z не меньше 1;
- ожидаемая индексная компонента за 32 бара против входа не хуже −0,5%;
- первое и третье правила вместе.

Неизвестное значение не разрешает сделку по соответствующему правилу. Доступны 11 888 оценок беты из 11 946. Исправлен дополнительный дефект исследовательского переноса: правило, которому z не нужен, не должно зависеть от прогрева или ненулевой дисперсии z. Арифметика на общей зрелой области сверена с более ранним независимым расчётом; изменение будущих цен и удаление всего будущего хвоста не меняют прошлые признаки.

У QQQ-допуска серия убытков в сентябре выросла с 7 до 12, а модельная DD с 3,24% до 4,26%. Улучшение октября/ноября поэтому не доказывает сокращение стопов во всех фазах. Смена доступных сделок и дневных пауз иногда увеличивает их число после добавления фильтра — портфель каждый раз моделируется заново.

Это ранее изученная история, не независимый holdout. Известное закрытие сигнального бара не является доказанной ценой рыночного исполнения. Расчёт сохраняет консервативный порядок неоднозначных 15m касаний, ограничения портфеля и дневных потерь, но не воспроизводит реальные исполнения, шаг контрактов, финансирование, совместный с crypto счёт, плавающую просадку или forward-разрешение LIVE. Это закрытые входные когорты, не выписки календарного счёта. Июль и ноябрь неполные; родные контракты не предоставляют историю 2020–2025.
